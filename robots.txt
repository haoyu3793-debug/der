# Phoenix Park Deer Tracker
# Everything here is public and safe to index.

User-agent: *
Allow: /

# The API is for the page, not for a crawler. /api/auth/me in particular
# answers "who is asking?", which is a different answer for every visitor and
# not something worth having in a search index.
Disallow: /api/

# There is no sitemap yet. The reason used to be that a sitemap has to list
# absolute URLs and this site had no domain; it has one now, so that reason has
# expired and the only thing left is that nobody has written the file. Four
# pages is few enough that a crawler finds them all by following links, so this
# is a nicety rather than a gap. When somebody writes sitemap.xml, add:
#   Sitemap: https://deertracker.org/sitemap.xml
#
